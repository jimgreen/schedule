# Schedule MILP 调度平台

本项目提供柴油微电网的三层优化调度：`weekly_plan` 采用 168 个小时步长，`daily_plan` 采用 96 个 15 分钟步长，`hourly_plan` 采用未来 16 个 15 分钟步长并只执行当前 1 个步长。模型包含柴油机启停、爬坡、储能 SOC、风光消纳、可调负荷、联络线、备用和失负荷约束；柴油机油耗曲线用分段线性 MILP 表示。

三个模块各自保存优化参数、输入曲线、计划版本、输出结果和控制审计。日前计划可以接收周前计划基线，小时前计划可以接收日前计划基线；发布、回退、校核和首个 15 分钟模拟执行都限定在所属模块内。柴油机、风光、储能、可调负荷、联络线和共享电网模型由三个模块共同使用，历史计划仍保存完整输入快照，因此修改共享参数不会改变历史结果的校核依据。

## 启动

```powershell
python -m pip install -r requirements.txt
uvicorn api.main:app --host 0.0.0.0 --port 8000
```

浏览器访问 `http://localhost:8000/`。后台自动创建 `D:\codex\sqldb\realtime\schedule\schedule.db` SQLite 数据库，保存共享资产、油耗曲线、三层输入配置、计划版本、柴油消耗统计和模块控制审计。测试或其他部署可以通过 `SCHEDULE_DB_PATH` 覆盖默认路径。

Web 页面现在按真实 HTML 页面拆分，不再把功能挤在一个文档中。入口为 `/`；三个模块分别提供 `/weekly_plan/optimization.html`、`/weekly_plan/inputs.html`、`/weekly_plan/results.html`、`/weekly_plan/control.html`，日前和小时前使用相同的独立路径；共享资料位于 `/shared/devices.html` 与 `/shared/network.html`。每个页面只加载当前功能脚本，页面之间通过导航链接切换，页面固定在单一视口内，不使用横向或纵向滚动条。优化参数与输入曲线分别保存，浏览器会暂存未保存草稿并在服务器数据变化时提示冲突；JSON 模型和配置支持导入、导出、查询、修改和保存。

求解器可切换 `cplex`、`highs`、`cbc`；三个计划始终按 MILP 求解。CPLEX 需要本机安装 CPLEX Python API，HiGHS 由 `highspy` 提供，CBC 需要 `cbc` 命令在 PATH 中。不可用的求解器会返回明确错误，不会降级为 LP。

## 操作与查询

- 优化参数提供快速试算、均衡求解、精细求解三个快捷设置，仅调整时限和 MIP Gap，不覆盖目标函数权重。页面顶部显示后台求解占用状态。
- 输入曲线支持平坦、峰谷和首尾插值模板；复制上级模块曲线时按计划起点对齐并校验覆盖范围。模板可以撤销，也可恢复当前曲线的保存值，保存后才参与计算。
- 输出结果的“版本管理”提供状态筛选、准确总数、分页、版本对比和导出。曲线、明细、统计独立展示，避免工具栏挤占工作区。
- 控制审计拆分为控制操作、审计列表和校核明细。审计可按动作和关键字筛选；长详情分页阅读；CSV 导出包含全部匹配记录，并使用一致的 SQLite 查询快照。
- 共享设备支持复制单台设备参数和恢复加载值。保存期间继续编辑的设备或电网模型草稿会保留，并提示再次保存。

当前仍采用手动触发滚动优化；执行操作记录模拟指令。共享电网模型资料用于维护和查询，尚未形成线路潮流约束。

## 模型精简与验证

启停变量由二进制开机状态、状态转移和启停状态约束严格确定，无须独立二进制分支。柴油油耗曲线保留精确的增量式 MILP；移除了已由相邻分段约束隐含的重复约束。默认算例的二进制变量数由周前 2016、日前 1152、小时前 192，分别减至 1344、768、128。

2026-11-18 使用本机 CPLEX、30 秒时限、零 MIP Gap 对照原模型，三层均达到最优，目标值差小于 `1e-4`。交替重复 6 组小时前建模与求解，总耗时中位数约为 0.339 秒和 0.342 秒；本次主要收益为减少整数变量，尚不能据此声称整体求解更快。运行时仍记录各阶段耗时，便于继续评估实际数据规模。
